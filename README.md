# Stripe API Reference

A responsive API reference interface built with React, Vite, TypeScript, and Markdoc.

## Requirements

- Node.js 22.13 or newer

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```

The project also includes `vercel.json` for deployment on Vercel.
